## 2. Interactive CLI Diagnostics
Before asking for help, run self-diagnostics locally:
```bash
# Run environment and daemon doctor check
aegis doctor

# Run project config validation
aegis validate

# View interactive feature demo
aegis demo
```

- **Feature Proposals**: Submit an issue using the Feature Request template.
